# Changelog

The release PR (`dev` → `main`) adds a section for its version, built from each merged PR's
`Release notes:` line. The app shows the sections newer than the user's previous version in the
What's New sheet after an update (pwa-offline.md §7.4, PV-11). Write for scouters, not developers.
